# NorthCents — Legal

Public legal documents for the [NorthCents](https://northcents.com) personal-finance app. Published with GitHub Pages.

## Contents

- [`privacy/`](./privacy/) — Privacy Policy (effective May 1, 2026)

## Editing

The documents are plain HTML. Edit the files directly in this repo and commit; GitHub Pages redeploys in about a minute.

## Custom domain

Once `northcents.com` is purchased, point a CNAME record at `northcentstechnologies.github.io` and add a `CNAME` file to this repo containing `northcents.com`. GitHub Pages will then serve the documents at `https://northcents.com/privacy/` automatically.
